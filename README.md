Нативные инструменты для разработчика и сервисы вокруг них: Swift/SwiftUI на macOS, Python и TypeScript
на бэкенде, интеграции с LLM и агентами. Локально, быстро, без лишних слоёв.

## Стек

**macOS / iOS** — Swift, SwiftUI, AppKit, UIKit, CoreAnimation, SwiftPM, XCTest
**Терминалы** — SwiftTerm, PTY, работа с окнами и меню, файловые API
**Бэкенд** — Python, Django, Flask, REST, SQL/SQLite, Docker и Compose
**Фронтенд** — TypeScript, JavaScript, Next.js 15 / React 19, Node.js, HTML/CSS/SCSS
**LLM и агенты** — MCP-серверы, DeepSeek и OpenAI-совместимые API, локальный инференс (llama.cpp)
**Интеграции** — Ozon, Wildberries, OpenWeatherMap, телеграм-боты, отчётность и аналитика
**Инфраструктура** — macOS, Linux, git, ssh, shell, сборка и подпись нативных приложений
